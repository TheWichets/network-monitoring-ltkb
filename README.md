# NetMon 
Ứng dụng giám sát an toàn mạng được xây dựng bằng Python

## Chức năng
- Phát hiện thiết bị thông qua ARP, theo dõi trạng thái Online/Offline
- Kiểm tra kết nối và đo độ trễ
- Giám sát cổng, phát hiện cổng mới mở
- Thống kê lưu lượng từng card mạng
- Phát hiện bất thường: thiết bị lạ, ARP spoofing, dấu hiệu SYN flood / port scan, lưu lượng tăng đột biến
- Ghi nhận sự kiện, lịch sử cảnh báo và hiển thị trên dashboard web
